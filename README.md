## 🌿 Landing Page — EcoPlant (React + Vite)

Landing page de práctica para un servicio ficticio de suscripción de plantas, construida desde cero con React y Vite.

**Stack:** React, Vite, CSS
**Características:**
- Estructura por componentes (Header, Hero, Features, Footer)
- Diseño responsive
- Deploy en producción con Vercel
